Brand-standard Lucide line icon (stroke 2, round caps, `currentColor`) — use everywhere instead of emoji or hand-drawn SVG.

```jsx
<Icon name="shopping-cart" size={20} />
<Icon name="zap" size={18} color="var(--action)" />
```

Requires `<script src="https://unpkg.com/lucide@latest"></script>` on the page. Prefer commerce motifs where meaningful: `package`, `truck`, `star`, `heart`, `tag`, `message-circle`, `trending-up`, `sparkles`. Size 16 inline, 18–20 in buttons, 24 standalone, 48 inside tinted bubbles.
