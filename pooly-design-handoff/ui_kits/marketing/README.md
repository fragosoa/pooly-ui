# UI kit — Marketing landing

The new commercial landing page expressing the e-commerce reposition. Open `index.html`. Single self-contained file.

## Sections
Sticky nav → **hero** (Spanish headline + the real `ReportCard` as the hero visual + a "4:38 de encuesta a insight" float) → **trust bar** (Shopify/VTEX/WooCommerce/Mercado Libre/Tiendanube) → **how it works** (3 steps) → **feature** (journey-moment cards, positioning vs. Typeform) → **dark stats band** (orange accent numbers) → **testimonials** → **pricing** (Starter / Growth featured / Scale) → **dark CTA band** → **footer**.

## Notes
- Marketing layout CSS is inline in the file's `<style>`; interactive elements (`Button`, `Badge`, `Avatar`, `Card`, `ReportCard`) come from the bundle.
- Copy follows the rebrand voice: business outcomes, time emphasis ("en menos de 5 minutos"), "clientes" not "ciudadanos", no emoji.
- The hero deliberately reuses the product's `ReportCard` so the marketing promise shows the real artifact.

> Recreation, not production code.
